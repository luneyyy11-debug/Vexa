# Vexa

Vexa's business website, built with Next.js, React, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Template and icons

This site is adapted from [Cruip's Open React / Next.js Template](https://github.com/cruip/open-react-template), licensed under GPL-3.0. Icons are provided by [Lucide](https://lucide.dev/) and [React Icons](https://react-icons.github.io/react-icons/).
